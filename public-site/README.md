# 塔卫二档案库 · 玩家分享站

面向其他《明日方舟：终末地》玩家的**只读档案站**：把同人整理的条目、干员关联和标签筛选做成网页，方便分享给朋友或公开浏览。不含编辑、不含主时间线。

本目录可直接用于 **GitHub Pages** 发布。

## 能做什么

- **首页 · 干员**：列出所有带 `#干员档案` 的条目；点干员可看相关条目
- **全部条目** / 侧栏目录：按标题浏览
- **标签筛选**：形式 / 人物 / 地点 / 组织；支持并集、交集与一键清除
- **搜索**：按标题检索
- 侧栏可收起；手机端为抽屉侧栏

## 从本地 vault 生成数据

在仓库根目录执行：

```bash
python build_public_site.py
```

会更新 `public-site/data/notes.json`（分享出去的内容来自这次导出）。

## 本地预览

不要直接双击 HTML。在 `public-site` 目录起静态服务，例如：

```bash
cd public-site
python -m http.server 8080
```

浏览器打开 `http://127.0.0.1:8080/`。

## 发布到 GitHub Pages（分享给其他玩家）

1. 先跑一遍 `build_public_site.py`，确认 `data/notes.json` 是最新想分享的内容。
2. 将本文件夹内容推到仓库的 `gh-pages` 分支，或把仓库 Pages 源设为 `/public-site`（若整仓发布）。
3. 确认存在 `.nojekyll`（已附带），避免 Jekyll 忽略 `data/` 相关路径。

发布后把链接发给其他玩家即可打开浏览，无需安装桌面版。
